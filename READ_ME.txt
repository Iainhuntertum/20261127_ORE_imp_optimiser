# Imp Optimiser reproducibility package

This package reproduces the human-derived impedance fit and the stationary
and continual learning benchmarks in *Imp Optimiser: Impedance-Inspired
Optimisation as a Dynamical System*.

## Files

- 20261127_ORE_imp_opt_fit_data.mat contains the processed human fit inputs
  and the trial-window bounds.
- 20261127_ORE_imp_opt_func.py fits the impedance mapping and generates
  Figure 4.
- 20261127_ORE_imp_opt_params.npy contains the verified fitted values in
  the order A_plus, mu, s.
- 20261127_ORE_imp_main.py generates the synthetic data, runs the
  benchmarks and produces Figures 1–3 and the gain-sweep results.
- 20261127_verified_results/ contains the per-seed stationary and continual
  metrics, the gain-sweep summary and the benchmark run configuration.

## Set up the environment

The release was verified on Windows with Python 3.13.7, NumPy 2.3.3,
SciPy 1.16.2, Matplotlib 3.10.6 and PyTorch 2.8.0 (CPU).

Open PowerShell in the folder containing this README and run:

    py -3.13 -m venv .venv
    ./.venv/Scripts/python.exe -m pip install numpy==2.3.3 scipy==1.16.2 matplotlib==3.10.6
    ./.venv/Scripts/python.exe -m pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cpu

## Reproduce Figure 4 and the fitted parameters

    ./.venv/Scripts/python.exe -X utf8 ./20261127_ORE_imp_opt_func.py

The fitter reads the MAT file beside the script. It uses 660 same-trial
pairs of normalised changes in maximum perpendicular error and
co-contraction index from 11 control participants. Control participant 8
is excluded. The saved bounds 951 and 1011 select MATLAB columns 952
through 1011 inclusive, giving 60 trials per included participant.

The script writes fit_results/human_impedance_fit.pdf and
fit_results/refitted_imp_opt_params.npy in the current working directory.
The generated parameter file matches 20261127_ORE_imp_opt_params.npy byte
for byte in the verified environment:

    A_plus = 0.5111801242844629
    mu     = 0.06880547358929091
    s      = 0.24854385405434803

## Reproduce the benchmarks

    ./.venv/Scripts/python.exe -X utf8 ./20261127_ORE_imp_main.py --device cpu --run_id ore --no_titles

The benchmark reads 20261127_ORE_imp_opt_params.npy from beside the script.
To use the vector from your fit directly, add
--phi_params_path ./fit_results/refitted_imp_opt_params.npy
and choose a separate run ID with --run_id ore_refit.

The run uses seeds 0–4, a batch size of 64 and 800 optimiser updates.
The continual experiment uses 400 updates per task. Evaluation is every
10 updates. The gain sweep uses k = 0.1, 0.3, 1.0 and 3.0.

The script writes metrics to results/ore/ and plots to figures/ore/
beside the benchmark script and prints both full paths in the terminal.
Use --out_root to choose another base folder.
Compare stationary_metrics.csv, continual_metrics.csv and k_sweep.csv
with their counterparts in 20261127_verified_results/. The gain-sweep
table uses the values in k_sweep.csv rounded to four decimal places.
The imp_results.json file records the run settings and summary statistics.
